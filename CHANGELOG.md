# Changelog

All notable changes to AtlasForge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - Alpha 0

Initial alpha release with core product loop:

- Workspace root management with folder picker
- Repository scanning with stable identity
- Repository health profiling and audit
- Verification command detection and execution
- Knowledge indexing and search
- AI provider configuration and report generation
- Patch proposal and approval workflow
- GitHub read integration
- Automation rules engine
- Job timeline with evidence
- Error boundaries, loading states, and empty states
- NSIS/MSI installer for Windows x64
